# AndroidLabs

A collection of independent Android labs. Each lab has its own Android Studio project and build instructions.

| Lab | App | Project |
| --- | --- | --- |
| BankingHell | Northstar Bank | [BankingHell](BankingHell/) |

Open a lab directory in Android Studio, or follow that lab's README for a command-line build. Build outputs and local machine settings are excluded from version control.
