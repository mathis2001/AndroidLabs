# Hide'N Seek

Hide'N Seek is a fictional secure messaging app for an Android CTF lab. It includes seeded conversations, preferences, and backup and restore screens. In a conversation, tap **+** to attach an image; shared images appear in the chat and open in the photo viewer.

Open this directory in Android Studio and build the `app` module, or run `bash scripts/build-local.sh` with Android SDK platform 34 and build-tools 35.0.0 installed. The debug APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

All names, messages, and identity details in the app are fictional.

The bundled chat photographs and their sources are listed in [ASSET_CREDITS.md](ASSET_CREDITS.md).
